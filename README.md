# Library Management System

A web-based Library Management System built using HTML, CSS, JavaScript, Node.js, and Docker.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- npm
- Docker

## Project Files
- `index.html` — Web page
- `style.css` — Page styling
- `script.js` — Frontend logic
- `server.js` — Node.js server
- `package.json` — Project configuration
- `Dockerfile` — Docker configuration

## Installation

Install Node.js, then run:

```bash
npm install
npm start
```

Open the local URL shown by your server in the terminal.

## Docker

Build the image:

```bash
docker build -t library-management-system .
```

Run the container using the port configured by your application.
